# Security

Please report security problems privately through
[GitHub security advisories](https://github.com/mmukhanov/nimbus-drive/security/advisories/new)
rather than in a public issue.

Worth reporting: anything that lets another local user or process reach your Drive, exposes
your rclone token, or makes Nimbus Drive delete or overwrite files you did not ask it to.

Nimbus Drive is a beta maintained in spare time; there is no guaranteed response time.
